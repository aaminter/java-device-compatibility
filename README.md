# Java Device Compatibility

![Java CI](https://github.com/aaminter/dz7/actions/workflows/ci.yml/badge.svg)

Учебная реализация выбора варианта приложения с учётом операционной системы и года выпуска устройства.

## Демонстрируемые темы
- условные операторы;
- составные логические выражения;
- ветвление по нескольким параметрам;
- обработка неподдерживаемых значений.

## Запуск
Требуется JDK. Откройте проект в IntelliJ IDEA и запустите класс `main`.

## Статус
Учебный консольный пример. Не является реальным механизмом определения совместимости устройств.
